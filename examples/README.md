# Example workflow

1. Copy the sample queue to `data/products_queue.csv`.
2. Start the local GUI with `render-rise-gui`.
3. Attach a master image. The row moves from `NEW` to `HAS_MASTER`.
4. Inspect and approve the image manually.
5. Build the upscaled, multi-ratio export package.
6. Add licensed mockup templates and generate the final listing set.
7. Review the customer-facing package before publishing it to Dropbox.
8. Generate the delivery PDF, then manually upload or schedule the Etsy listing.

The sample queue contains fictional data and no customer links or production identifiers.
